# X52 reference photographs

These are actual manufacturer photographs of the **non-Pro X52** product, downloaded
2026-09-21 from Logitech's product gallery. They match the original X52 hardware
layout; branding/illumination can differ from the user's Saitek-branded unit.
They are not AI-generated and are not evidence for any HID control-number mapping.

Product source: https://www.logitech.com/en-us/shop/p/x52-space-flight-simulator-controller

Original image URLs:

- https://resource.logitech.com/content/dam/gaming/en/products/x52-hotas/x52-gallery-1.png
- https://resource.logitech.com/content/dam/gaming/en/products/x52-hotas/x52-gallery-2.png
- https://resource.logitech.com/content/dam/gaming/en/products/x52-hotas/x52-gallery-3.png
- https://resource.logitech.com/content/dam/gaming/en/products/x52-hotas/x52-gallery-5.png
- https://resource.logitech.com/content/dam/gaming/en/products/x52-hotas/x52-feature-1.png

The picker embeds those five originals as RCDATA and draws them with Windows GDI+.
Gallery-5 provides a side view for the trigger and pinkie highlight. Red control
circles are native vector overlays; the manufacturer PNGs remain unchanged.
The display viewports trim empty margins and show the throttle area of feature-1;
the source files remain unchanged. The remaining downloaded gallery/feature views are research
references and are not embedded.

Image rights remain with Logitech/Saitek. The repository's source-code GPL license
does not relicense these manufacturer photographs. Distribution permission for the
photos has not been established; resolve that before publishing a release containing
them. They are included here for the user's requested local hardware-identification UI.
