# Profile authoring

The Battlefield profiles tab imports the user's BF3/BF4 settings and authors
original-X52 PR0 drafts using the installed Logitech template. No personal game
bindings or vendor profile files are bundled here.

Plans live in `%LOCALAPPDATA%/X52BattlefieldMapper/bf3-authoring.json` and
`bf4-authoring.json`; exports use new filenames in its `profiles` subdirectory.
See `docs/profile-authoring.md` for supported commands and validation.
