# PS28 device identity

Original Saitek X52 Flight Control System, PS28, VID 0x06A3, PID 0x075C.
Do not treat X52 Pro as equivalent. Authoritative identification uses HID attributes,
not product name text. Strings are displayed for the operator.

On 2026-09-21 the attached controller was opened read-only and decoded successfully.
Its joystick collection (desktop page 1, usage 4) reports input/output/feature lengths
15/0/0 and report ID 0. These lengths describe the selected collection and do not
prove that every possible vendor interface lacks output commands.

Full descriptor-capability observations are in PROJECT.md. Physical assignments
require operating the device. Do not use centring, byte location or generic HID
usage alone to infer throttle-to-stick health or a physical reset command.
